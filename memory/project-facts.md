# Project Facts

## Core Project

RTDL is a general-purpose spatial language/system. Its value is not that it can
hard-code one paper, but that paper apps force reusable APIs into the system.

## Paper App Lines

### LibRTS

LibRTS is the closed fifth paper-app line. Its paper-specific identity,
fixtures, author wrapper, comparison policy, and claim boundaries live under
`Paper-reproduction-apps/librts-paper`.

The existing RTDL system assets being tested are generic AABB operations:

```text
prepare_aabb_index_2d
query_aabb_index_2d
expanded_aabb_point_membership_rows_2d
aabb_intersection_pair_rows_2d
```

Goal5454 first proved a tiny author/RTDL OptiX same-input point-contains count
match (`5 == 5`) and RTDL exact fixture rows. The author example does not expose
pair rows, so author pair-relation equality remains unclaimed. Range queries,
mutations, paper datasets, and fair performance evidence remain open. Embree is
not part of this campaign.

Goal5455 adds range-contains count agreement on a fixture that distinguishes
the correct `indexed_box_contains_query_box` direction (`5`) from the reversed
direction (`2`). Author and RTDL OptiX both report `5`. Range-intersects and
mutations remain open.

Goal5456 completes the bounded query surface: range-intersects count is `8`
while range-contains is `5`; author and RTDL OptiX both report `8`, and RTDL's
generic native intersection-row API emits all eight expected rows.

Goals5457-5460 close bounded mutation semantics. RTDL now has a generic
`MutableAabbIndex2D` with stable IDs and atomic snapshot rebuilds. On local
Linux, patched-author RTSpatial and RTDL OptiX both produce mutation counts
`[2,1,0,1,0]` and append ID `2`. This is semantic agreement, not native
incremental implementation or performance parity. The author build requires a
disclosed one-line fix from `tempSizeInBytes` to `tempUpdateSizeInBytes` in
`updateInstanceAccel`.

Goals5461-5462 upgrade pure OptiX Update to a generic native sparse-slot refit
with stable-ID validation and rollback code. Insert/Delete/Clear remain atomic
snapshot rebuilds. On local GTX1070, RTDL sparse refit versus RTDL rebuild is
about `12.62x` for 4,096 boxes and `15.63x` for 65,536 boxes. These are generic
same-host system diagnostics, not LibRTS paper or author-performance evidence.
Goal5463 verifies the rollback contract on Linux hardware after candidate GAS
update and makes rollback failure permanently fail closed by poisoning the
prepared handle.

Goals5464-5465 add the first bounded PIP gate from the exact author AE source
chain (`PPoPPAE@d605fe1`, `RTSpatial@7c54c18`, and
`SpatialQueryBenchmark@9140ad9`). On local GTX1070 functional evidence, author
and RTDL OptiX both report `4` polygon-refined PIP hits on the same three-polygon/five-
point fixture. RTDL emits all four expected relation rows. The fixture has `5`
MBR-only candidates, so exact polygon refinement is discriminating. Author
pair-row agreement, Figure 12, Ray-Multicast, and performance remain unclaimed.
Goals5464-5465 are implemented / external review pending.

Goals5466-5467 raise PIP to a Level-B public-source representative input: 64
simple Block Group polygons (`30,635` vertices) and 100K points generated by
the pinned author generator with seed 0. Standard RTDL PIP produces `71,624`
rows versus author `71,626`; the mismatch is preserved. A composed route using
generic RTDL OptiX AABB candidates plus an app-owned Numba CUDA adapter for the
author float32/sentinel/fast-math PNPOLY produces `71,626`, and all author/RTDL
pair rows match with SHA-256 `7d30e35b...26c7b`. This is not exact paper data,
Figure 12, or performance evidence. Goals5466-5467 are implemented / review
pending.

Goals5468-5469 pin the paper/source Ray-Multicast mechanism and establish that
it is static disjoint-layer traversal fanout, not ordinary batching. RTDL now
has a generic Python reference plan and cost selector plus a behavioral
Contact-Manifold non-app consumer. Native layer encoding, launch fanout,
payload filtering, and load telemetry remain unimplemented. The next POD work
is a bounded spike only, pending strict external review.

### RayJoin

RayJoin drove the device-column/row-buffer/prepared-pipeline work and exposed a
major lesson: text writer output can dominate when a paper app is benchmarked as
a file-dumping program. For RTDL as a language, the stronger model is
writer-free binary operators inside a larger pipeline.

### RT-BarnesHut

RT-BarnesHut established the aggregate-hierarchy abstraction:

```text
AggregateHierarchy3D
SizeDistanceOpening
ContinuationPayloadOpening
aggregate frontier/reduce reference and Numba parity
```

The bounded same-input line closed, but full independent tree construction and
whole-paper performance remain separate future work.

### RT-DBSCAN

RT-DBSCAN established component-partition correctness discipline. A signature
gate was not enough; the line was corrected to compare partition equivalence and
core flags.

### X-HD

X-HD is a completed historical line. Bounded same-input HDResult reproduction
is complete. Its system extraction produced these generic RTDL APIs:

```text
pairwise L2 rows
nearest witness
max-nearest reducer
grid cell MBR descriptors
cell-MBR candidate rows
nearest-state frontier split
cell-MBR traversal ABI row table
backend-assisted AABB front door
dimension-generic reference row-table front door
```
