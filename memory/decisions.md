## D202. Goal5835 Is An Inherited-Evidence Semantic Projection

The Goal5835 result is genuine but narrower than an executed application. Its
receipt reconstructs application-shaped objects, proves that their normalized
bytes equal exact Goal5834-B3 fixtures, and composes 33 inherited true-OptiX
launches. It does not call the app execution front door, build trajectory or
positive complete-mesh inputs, or add a Goal5835 GPU launch. The controlling
class is therefore
`BOUNDED_APP_SEMANTIC_PROJECTION_WITH_INHERITED_TRUE_OPTIX_EVIDENCE`, while
`NOT_A_PAPER_APP` remains unchanged. Publish the narrowing append-only; never
rewrite the hash-bound historical source or authorities. Independent external
review is owner-deferred and no consensus is claimed.

## D201. Directed Connectivity Is Predicate-Significant and Terminates Goal5836

The Sui author benchmark's strongly connected directed obstacle-edge graph is
part of its collision predicate, not a performance-only implementation choice.
One-sided finite rays can miss when they begin inside a hollow round curve; the
directed graph supplies an outside-to-inside traversal direction. Goal5835's
unordered edge deduplication and arbitrary first direction do not preserve that
invariant and explicitly exclude initial overlap. Therefore A1 classifies a
`MATERIAL_PREDICATE_DIFFERENCE`, preserves Goal5835 as `NOT_A_PAPER_APP`, and
makes A2--A5 unreachable. Any generic orientation/connectivity repair requires
a new owner-defined and preregistered goal.

## D197. Goal5832 Separates Family Shape, Protocol Instance, and Deployment

“Family” is no longer inferred from a Python class, enum member, wrapper, app
name or shared bytes.  `FamilyShapeV1` covers structural axes
`<G,R,V,E,H,B,C,X,L>`; `ProtocolInstanceV1` adds nominal semantics, verified IR,
ABI and proofs; `DeploymentV1` adds target, provider, generated artifacts and
actual executable identity.  Each domain has a distinct hash prefix.  Local
binders and declared sets normalize; role/view/operator/transition order and
channel ownership remain identity-bearing.  Goal5832 is a specification and
reference validator, not a generic compiler or generalization result.

## D196. Goal5831 Uses Layered Denominators Instead of “Two Families”

## D194. Goal5751 Formal IR Compiles to Seven Audited Numba PTX Leaves

The canonical ABI includes launch index, frozen role/stage tags and a frozen
runtime-status map. Deterministic codegen accepts exact verified IR plus exact
ABI and external any-hit proof authority; original user callables/source never

integer arithmetic remains fail-closed pending a reviewed no-wrap lowering.
Goal5751 remains open for composition, OptiX runtime, atomic status and
interpreter/device differential evidence.

## D193. Goal5751 Uses Canonical SoA ABI and External Any-Hit Proof Authority

Formal Callback IR crosses the backend boundary only through a deterministic
ABI recompiled from the exact verified program. Compound values flatten in
semantic order; read-only views use one typed device pointer per scalar column
plus length, not opaque application structs. Device faults use an RTDL-owned
per-launch status envelope; Python/Numba exceptions are not an ABI.

Any-hit delivery cannot be authorized by a manifest declaration. Codegen
requires an out-of-program authority binding exact IR/effect/delivery/proof
identity and a recognized proof class. Missing or stale authority fails closed.
This decision defines admission/layout only; device race safety and CPU/device
equivalence remain Goal5751 obligations.

## D1. RTDL Core Must Stay Generic

and tolerance policy. RTDL core must use app-neutral terminology and must not
contain `xhd`, `rayjoin`, `barneshut`, `dbscan`, paper, author, or output-format
semantics unless the feature is explicitly an app support registry/documentation
surface.

## D2. Bounded Correctness Is Not Full Paper Reproduction

Bounded same-input gates are valid evidence, but they are not full paper
reproduction. Full paper reproduction requires dataset provenance, phase
semantics, author contract alignment, and fair performance denominator
alignment.

## D3. Statistics Do Not Prove Exact Dataset Identity

For X-HD, matching counts, Gini, or table statistics is not enough to call a
dataset an exact paper input. Exact paper dataset status requires file/hash or
equivalent provenance evidence.

## D4. Use Same-Source Level B When Exact Inputs Are Missing

When exact paper inputs are unavailable, the project may run Level B same-source
representative gates, clearly labeled as representative and not exact paper
reproduction.

## D5. No Performance Ratio Without Matched Denominator

Do not report author-vs-RTDL ratios unless dataset, hardware, phase boundary,
runtime regime, and included setup/output costs are aligned. If not aligned,
publish separate phase numbers and explicitly refuse the ratio.
