# Claim Boundaries

Status: V3 rebuild tutorial.

Every performance sentence must name:

- the exact benchmark row;
- the backend;
- the partner, if any;
- the output contract;
- the same-contract baseline;
- the hardware;
- the command or runner;
- the artifact path.

Allowed wording:

```text
On the RTX 4000 Ada pod, this exact V3 row showed an OptiX-over-Embree win in
the copied Phoenix V3 evidence artifact.
```

Blocked wording:

```text
Broad V3-over-V2.x superiority.
All benchmark apps accelerated on RT cores.
Backend name alone proves speed.
```

The current Phoenix evidence makes V3 worth continuing. It does not by itself
publish V3. Public release wording requires final docs, setup, tutorial, and
review gates.
