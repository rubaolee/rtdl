# Historical Release Reports

This directory preserves older RTDL release packets for audit reconstruction.
They are not the current user surface.

Current release status: none promoted. V3 is being rebuilt under
[V3 Rebuild Control](../../rebuild/v3/README.md).

## Rule

A historical release packet is authoritative only for its own tag. Do not use a
previous packet to override the current rebuild boundary or to authorize public
performance wording.

Old V3/V4 packets that were previously in the active release doorway are now in
[Quarantined Old V3/V4 Release Surface](../quarantine_v3_v4_reset_2026-06-20/README.md).
