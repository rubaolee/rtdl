# RTDL V4.0.0 Publication Note

Status: published source-tree release note for tag `v4.0.0`.

V4.0.0 is published as the current source-tree major release. The front page,
docs index, tutorials, examples, source-tree doctor, and release-report doorway
now point to V4.0.0 first.

The previous V3.0.2 release package remains in tree because it is still the
best reference for the broader ten-app benchmark route matrix. It is no longer
the current doorway.

Publication does not widen the technical claim surface beyond the M1 route and
the evidence listed in this package.
