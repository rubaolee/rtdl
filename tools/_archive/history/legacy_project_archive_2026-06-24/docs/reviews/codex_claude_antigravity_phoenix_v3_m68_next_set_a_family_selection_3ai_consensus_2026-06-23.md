## Decision

M68 is accepted because:

- Barnes-Hut is already counted internally by M67 and must not be reopened as
  Barnes-Hut-specific work.
- Spatial/RayJoin topology-stream repeat execution is M66 non-go because the
  current route removes no new physical work.
- LibRTS is Set-B control work, not the next Set-A runtime family.
- Hausdorff is already above the frozen Set-A app-win threshold.
- RTNN remains below the app-win threshold (`1.003327x`) and has a generic
  productized `fixed_radius_ranked_summary_3d_prepared_session` surface with
  existing focused repeat50 evidence.

The RTNN evidence boundary is part of the decision:

- runner vs legacy runner-wall: `1.370176x`
- runner vs legacy hot query: `0.988781x`

The runner-wall result is repeat50 focused evidence only. It is not a
single-shot speedup claim, whole-RTNN claim, public claim, broad V3-over-V2
claim, or release claim.
