2026-08-29 related-work revision deliberately does not enforce the submission
page budget; compression is a later, separate pass after the contribution and
literature boundaries are stable. Its
performance section and compact artifact use the current-source same-target
Direct/PyOptiX/RTDL result: 324 workers, 7,128 registered timings, and 18
comparison rows. A deterministic, manifest-bound anonymous evidence package is
built as `rtdl_cgo2027_anonymous_artifact.tar.gz`. Submission still requires an
anonymous artifact URL or approved supplementary upload and the final
deanonymization diff check.

The source intentionally uses `review,anonymous`, contains no author identity,
affiliation, acknowledgement, repository URL, internal goal number, local path,
POD endpoint, or internal evidence filename in the rendered paper.

Before submission:

1. assign the anonymous artifact URL;
2. complete the fresh final-byte gate (the historical
   `anonymization_gate.md` is explicitly superseded);
3. run the final bibliography and deanonymizing-self-citation review;
4. absorb external review only by correcting or narrowing claims.
