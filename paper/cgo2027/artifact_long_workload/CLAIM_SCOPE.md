# Claim scope

The projection retains all 240 formal worker rows, 1,248 timed samples, 120
warmups, 80 three-arm paired cells, input identities, output hashes, execution
orders, CPU-affinity observations, and ten complete/prepared evaluations. The
verifier reconstructs worker medians, paired ratios, engineering thresholds,
and the reported table values without importing RTDL.

The transaction covers five operation units from three application mappings on
one RTX A4500. Only the cit-Patents/4M prepared row is a multi-second natural
computation. Six historical mappings are not measured. Particle uses a fixed
app-shaped standard-library specialization. The public PyOptiX and RTDL paths
are output-equivalent but not operation-identical. CPU 8 was selected after a
disclosed diagnosis, GPU clocks were not locked, and formal peak memory was not
captured.

This package is derived evidence. It cannot establish that the raw files were
honestly produced, rerun the GPU work, independently validate application
semantics, or authorize broad performance, productivity, arbitrary-callback,
app-independent-engine, or public claims. The retained private archive and its
independent clean-checkout recount remain the custody authority.
