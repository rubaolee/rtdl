## Architecture And Generality

Hausdorff distance remains an application composition. RTDL core was not given
an X-HD- or paper-named primitive. The app composes generic system assets:

```text
pairwise L2 candidate rows
-> nearest-witness reduction
-> max-nearest scalar reduction
```

For larger routes it also uses generic grid/cell-MBR descriptors, nearest-state
frontiers, native inline-nearest traversal, and partner-facing 2-D
max-of-nearest execution. Goal5128 supplies a non-Hausdorff consumer
(facility service radius / worst-served demand), so the nearest/max-nearest
surface is not justified only by X-HD.

Paper-specific ownership remains in the app:

```text
author hd_exec wrapper and build patch
input acquisition and preprocessing
same-input comparator and tolerances
author-compatible JSON shape
performance-regime labels and claim boundaries
```
