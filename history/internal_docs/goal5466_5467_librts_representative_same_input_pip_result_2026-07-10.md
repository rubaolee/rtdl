unmodified author count       71,626

## Semantic Diagnosis

An app-owned diagnostic compared:

1. standard RTDL `point_in_polygon` rows;
2. NumPy float32 outer-ring PNPOLY;
3. an emulation of the author's float32 `(0,0)` sentinel layout;
4. actual author rows from comparator-only instrumentation.

The actual author and standard RTDL sets differ on six relations, for a net
count difference of two. Several relations are close to shared polygon edges.
One author-only relation is `0.0517` coordinate units from the true outer edge,
showing that the author's sentinel layout is an implementation semantic, not
only a conventional boundary policy.

The standard RTDL route remains valid for standard polygon semantics. It is not
silently changed to imitate the author artifact.

## Comparator-Only Author Instrumentation

The app-owned patch `goal5467_export_author_pip_rows.patch` copies the already
collected result queue to the path in `LIBRTS_PIP_ROW_DUMP` after query
completion. It does not edit:

- the PNPOLY function;
- polygon/point conversion;
- index insertion or query;
- result queue append;
- the public count.

The gate runs both binaries. Each reports `71,626`, so instrumentation cannot
substitute a different result count.

## RTDL App-Compatible Route

The compatibility route is composition, not a new core primitive:

```text
generic RTDL OptiX expanded-AABB point-membership candidate rows
-> conservative generic candidate expansion (1e-5)
-> app-owned Numba CUDA float32/fast-math PNPOLY
-> app-owned author sentinel vertex layout
-> canonical (point_id, polygon_id) rows
```

System-owned capability:

```text
expanded_aabb_point_membership_rows_2d
contract = generic_expanded_aabb_point_membership_rows_2d_v1
candidate_count = 154,155
rt_core_accelerated = true
native_engine_customization = false
```

App-owned compatibility:

```text
partner = numba_cuda
fastmath = true
app_semantics = pinned_author_pnpoly_float32_sentinel_layout
```

No `src/rtdsl` or `src/native` change was needed.

## Authorized Claim

```text
On one Level-B public-source representative input with 64 simple Block Group
polygons and 100,000 points from the pinned author generator, the unmodified
author PIP, comparator-instrumented author PIP, and RTDL app-compatible
OptiX+Numba route all produce 71,626 rows. The complete author and RTDL relation
sets are equal and have the same canonical SHA-256.
```

## Required Caveat

```text
The standard RTDL point_in_polygon route produces 71,624 rows. Exact artifact
agreement uses an app-owned compatibility adapter for the pinned author's
float32 sentinel layout and fast-math PNPOLY. This adapter is not a generic
RTDL language primitive.
```
