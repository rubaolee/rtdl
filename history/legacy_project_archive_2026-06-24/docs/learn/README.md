## Capability-Branch Requirement

Before this directory becomes a learner path again, each linked page must:

- describe one current V3 user problem;
- avoid old release claims unless they are rerun, verified, and scoped;
- use runnable commands from the current source tree;
- separate correctness, compatibility, and performance evidence;
- point to exact pod artifacts for every performance statement.

## Working Mental Model

```text
Python writes the application.
RTDL expresses the RT-shaped kernel.
Backends execute app-agnostic engine contracts.
```

This model is still the intended teaching shape, but it is not enough by
itself. Rebuilt V3 docs must show where that model helps users and must not
claim broad V2.x speed superiority.
