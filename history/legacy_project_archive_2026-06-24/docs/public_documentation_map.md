## Current User Message

RTDL is being reset to a clean V3 capability/quality branch. Old release
wording, old tutorial tracks, and old later-version front doors are not current
user guidance.

The rebuilt V3 must now provide:

- the user problem it solves;
- why the runtime trunk and row-scoped evidence are useful without claiming a
  broad V2.x speed victory;
- which benchmark rows are genuinely M7-qualified row-scoped;
- which rows need repair or removal;
- why V3 release remains blocked until capability-branch authorization;
- which docs/tutorials should return to the user path.

If a page does not help answer those questions, it is history or internal
material, not the beginner path.
