# V3 Capability-Branch Tutorial Path

Status: capability-branch learner path, not a release tutorial set.

This path teaches the current Phoenix V3 capability/evidence boundary. It is
intentionally small: learn the source tree, run a hello-world kernel, choose a
backend from evidence, inspect benchmark artifacts, and understand the GPU
partner gate.

Do not treat this as a published V3 release track. Public release wording stays
blocked until the Phase H capability/quality docs, setup path, and tutorials
pass final review.

## Shortest Safe Path

For a first pass, do not read every report. Follow this path:

1. [First Run](01_first_run.md) to prove the source tree works.
2. [Hello World](02_hello_world.md) to see the smallest RTDL program shape.
3. [Backend Choice](03_backend_choice.md) to learn that backend choice is
   explicit and evidence-scoped.
4. [Grouped Sum Prepared Query](07_grouped_sum_prepared_query.md) to inspect
   one M7-qualified row-scoped performance case.
5. [Claim Boundaries](06_claim_boundaries.md) to learn what the current V3
   rebuild still does not authorize.

That path teaches the current V3 loop without sending a new user through the
full evidence archive or implying broad V3-over-V2 speed superiority.
