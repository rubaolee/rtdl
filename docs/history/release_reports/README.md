# Historical Release Reports

This directory preserves RTDL release packets before the current release. They
are useful for audit reconstruction, but they are not the current user surface.

For current users, start with the
[RTDL v3.0.1 Release Package](../../release_reports/v3_0_1/README.md).

## Rule

A historical release packet is authoritative only for its own tag. Do not use a
previous packet to override current V3.0.1 docs, current claim boundaries, or
the V3.0.1 release package.
