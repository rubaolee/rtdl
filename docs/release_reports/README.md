# RTDL Current Release Reports

This directory is the current release doorway. It intentionally exposes the
active V4.0.0 release package first so users do not have to swim through
previous version packets before learning the system.

## Current Release

- [RTDL V4.0.0 Release Package](v4_0_0/README.md)

## Historical Release Packets

Previous release packets are preserved under
[Historical Release Reports](../history/release_reports/README.md), with the
immediately previous V3.0.2 source-tree packet kept at
[RTDL v3.0.2 Release Package](v3_0_2/README.md).

## Reading Rule

A release packet is authoritative only for its own tag. Current docs should
link to V4.0.0 first. Older packets remain useful for reconstructing why a claim
was allowed, blocked, or superseded, but they live behind the history boundary.
